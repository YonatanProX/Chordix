# מאגר הבדיקה

שלוש תיקיות עבודה:

```
bench/audio/    קבצי ה-mp3
bench/truth/    התשובות הנכונות — קובץ .txt אחד לכל שיר
bench/bench.html   דף המדידה
```

לכל שיר: `bench/audio/song1.mp3` + `bench/truth/song1.txt`.
השם חייב להיות זהה (חוץ מהסיומת), וגם לרשום בתוך הקובץ בשורת `קובץ:`.

---

## כותרת הקובץ

ארבע שורות, בכל סדר, לפני המקטע הראשון:

| שורה | ערך | הערות |
|---|---|---|
| `קובץ:` | `song1.mp3` | בדיוק כמו שם הקובץ ב-`audio/` |
| `סולם:` | `Am` | ראו "סולמות" למטה |
| `BPM:` | `92` | מספר. אפשר עשרוני: `92.5` |
| `משקל:` | `4/4` | `4/4` `3/4` `6/8` `12/8` `2/4` `9/8` `5/4` `7/8` |

## מקטעים

מקטע נפתח בשורה `[שם] mm:ss` — השם חופשי (`בית 1`, `פזמון`, `קטע ג`,
`מבוא`, `סיום`, `סולו`). הזמן הוא הרגע שבו המקטע **מתחיל**, כפי שקוראים
אותו בנגן.

**חשוב:** מקטעים שהם אותו דבר מוזיקלית צריכים שם שמתחיל אותו הדבר —
`פזמון 1`, `פזמון 2`, `פזמון 3`. ככה נמדד גם זיהוי המבנה ולא רק הגבולות.

השיר נסגר בשורה `[סוף] mm:ss` — הזמן שבו האודיו באמת נגמר. בלעדיה
אי אפשר למדוד את המקטע האחרון.

## תיבות

כל `| ... |` היא תיבה אחת. אפשר כמה תיבות בשורה, ואפשר לשבור שורות
איך שנוח — מה שנספר זה מספר התיבות, לא מספר השורות.

```
| Am | F | C | G |        ארבע תיבות, אקורד אחד בכל אחת
| Am  F |                 תיבה אחת, שני אקורדים (חצי-חצי)
| Am  F  C  G |           תיבה אחת, ארבעה אקורדים (רבע כל אחד)
| % |                     תיבה בלי אקורד — שקט, סולו תופים
```

מספר התיבות בכל מקטע צריך להתאים לזמן שלו לפי ה-BPM והמשקל. הדף יתריע
אם יש פער גדול, כי בדרך כלל זה אומר שנשמטה שורה.

## אקורדים

`שורש` + `סוג`, ואפשר `/בס`.

**שורשים:** `C C# Db D D# Eb E F F# Gb G G# A A# Bb B`

**סוגים** — בדיוק אלה, כי אלה 14 הסוגים שהמודל מכיר:

| כתיב | פירוש |
|---|---|
| *(ריק)* | מז'ור — `C` |
| `m` | מינור — `Am` |
| `7` | דומיננטי — `G7` |
| `maj7` | מז'ור שביעית — `Cmaj7` |
| `m7` | מינור שביעית — `Dm7` |
| `6` / `m6` | ששית — `C6` `Am6` |
| `mMaj7` | מינור עם מז'ור שביעית |
| `dim` / `dim7` / `m7b5` | מוקטן |
| `aug` | מוגדל |
| `sus2` / `sus4` | סוספנדד |

**בס:** `C/E`, `Am/C`.

אקורד שאינו ברשימה — כתבו את הקירוב הכי קרוב שבאמת מנגנים
(`Cadd9` → `C`, `C9` → `C7`).

## סולמות

`A` = לה מז'ור · `Am` = לה מינור.

אם השיר במודוס ולא במז'ור/מינור — **כתבו את זה**, זו בדיוק אחת השאלות
הפתוחות. `D hijaz`, `E phrygian`, `G mixolydian`, `D dorian`.
כרגע הזיהוי לא יודע לענות את התשובות האלה בכלל, והמדידה אמורה להראות
כמה מהרפרטואר זה תופס.

## אחרי שממלאים

פותחים את `bench.html`, גוררים פנימה את שתי התיקיות, ומקבלים טבלת ציונים.
מעתיקים את ה-JSON שבתחתית הדף ושולחים אותו — שם נמצאות כל המדידות.
